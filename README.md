🚀 Cryptocurrency Market Analysis Dashboard
An interactive data analytics project built with Power BI that visualizes and explores cryptocurrency market trends, including price movements, market capitalization, and trading volume across multiple digital assets.

📌 Project Summary
This project demonstrates how cryptocurrency market data can be transformed into actionable insights using data visualization. It uses Power BI to create an interactive dashboard based on a dataset of leading cryptocurrencies. The dashboard supports dynamic filtering and comparison to uncover patterns and trends across time and assets.

📂 Repository Contents
File Name	Description
CryptoCurrency_Dashboard.pbix	Power BI file containing the interactive dashboard
CryptoData.xlsx	Raw data source containing cryptocurrency metrics
PDF Representation	PDF snapshot or presentation view of the dashboard
README.md	Documentation and project overview (this file)

📊 Dashboard Features
📅 Time series analysis of daily cryptocurrency prices

🪙 Coin-wise comparison of market capitalization and volume

🔍 Interactive filters for coin selection and date ranges

📈 Trendlines and KPIs (Key Performance Indicators)

📌 Custom visuals using DAX and Power Query transformations

⚙️ Tech Stack
Tool/Technology	Purpose
Power BI Desktop	Data modeling, analysis, and dashboard creation
Microsoft Excel	Raw data storage and pre-processing
DAX & Power Query	Data transformations, filtering, calculated columns/measures

📥 How to Run the Project
Open CryptoCurrency_Dashboard.pbix in Power BI Desktop.

If prompted, reconnect to the dataset using CryptoData.xlsx from the same directory.

Use the filters and slicers to explore trends by coin or time period.

Open the PDF Representation file to view or share a static version of the dashboard.
